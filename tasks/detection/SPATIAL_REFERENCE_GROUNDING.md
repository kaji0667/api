# 方位参照定位

当前 API bbox 默认 `spatial_reference`：提取目标的全图方位，把方位带入无自身明确方位的参照物查询，检测参照物后用相对关系取共同范围，在扩展裁图中查询目标身份和属性。目标仍由原检测模型的 phrase-map/Hungarian 匹配选择；不按检测置信度选目标，不做 CLIP 图像裁块重排。

例如：`左下角的梯形草坪，右侧有道路，上方有建筑，旁边有池塘`。

1. 查询 `左下角的道路`、`左下角的建筑`、`左下角的池塘`。
2. 用左下区域、道路左侧、建筑下方和池塘附近的共同范围确定搜索区。
3. 扩展视野后查询 `梯形草坪`，在符合原图几何关系的实际候选中进行原文本匹配。
4. 将选中的目标框还原到原图坐标。参照框和搜索区本身不会作为答案。

支持中英文 1–3 条明确左/右/上/下/邻近关系及原解析器支持的属性句。目标的全图方位仅用于参照和原图范围，不在局部裁图中重复应用。参照已有明确全图方位时保留自身方位。未知句子、否定、复杂关系、缺参照、冲突范围或局部无合法目标回退原完整描述全图检测；此回退保证路径明确，不保证视觉正确。

沿用原检测 .25 confidence、.7 NMS、max_det 300、原本的 text encoder 和模型；几何使用已有 .10 padding、.25最小视野、.25邻近扩展、.8参照近重合排除。API其它任务和 VQA 不改变。

`HFSA_GROUNDING_POLICY=native` 可显式使用原全图对照。`clip_guarded` 不再是 API 策略，旧实验代码保留作历史；`bash scripts/serve_hfsa_api.sh` 会把先前导出的 `clip_guarded` 迁移到新策略。需在原 API 终端重启才加载当前代码。

机制测试：

```bash
python -B -m unittest tasks.detection.tests.test_spatial_reference_grounding -v
```

公开对照使用 `scripts/verify_spatial_reference_grounding.py predict` 固定115+80成员，完成后独立 `score` 命令读SHA绑定公开金标；不调用官网API。公开样本覆盖、完整分母、gain/loss与局限随后记录，测试通过不等于官网定位准确率提高。
